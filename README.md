# AI 日报 · AI Signal Ledger

面向公开阅读的 AI 资讯首页，每日沉淀最新 AI 领域动态。

## 概览

| 项目 | 说明 |
|------|------|
| **定位** | AI 领域每日信息汇点，覆盖大模型、产品、行业、论文、技巧五大方向 |
| **产出** | 纯静态单文件 HTML（零依赖），暗色主题 |
| **入口** | `index.html` — 固定为最新一期 |
| **助理** | 小汇（📥 每日信息汇点管家） |

## 日报结构（五版块固定顺序）

| 版块 | 配色 | 内容 |
|------|------|------|
| 模型发布/更新 | 靛蓝 `#6366f1` | 大模型发布、版本迭代、权重开源 |
| 产品发布/更新 | 粉 `#ec4899` | AI 产品/工具/平台发布、功能更新 |
| 行业动态 | 青 `#06b6d4` | 商业合作、融资、政策、人事 |
| 论文研究 | 橙 `#f59e0b` | 学术论文、研究突破、基准评测 |
| 技巧与观点 | 绿 `#10b981` | 使用技巧、教程、行业观点 |

## 数据源

- **主数据源**：AI HOT（`aihot.virxact.com`）
- **编者补充**：每日 WebSearch 交叉验证 30 家国内外知名 AI 公司官方动态，最多补充 5 条，逐条标注来源

## 目录结构

```
AI/
├── README.md             # 本文件
├── AGENTS.md             # 项目规则与工作流定义
├── template.html         # 设计模板（只读，不含真实数据）
├── index.html            # 最新一期公开首页
└── daily/                # 历史日报归档
    └── YYYY-MM-DD.html
```

## 使用方式

1. 由外部调度器按 `AGENTS.md` 规则每日执行
2. 生成前先将当前 `index.html` 归档至 `daily/YYYY-MM-DD.html`
3. 新内容写入 `index.html`，替换为最新一期
4. 同日重复生成为修订模式，直接覆盖当前 `index.html`

## 设计规范

- 暗色主题：背景 `#0a0e1a`，信号色 `#d9ff57`
- 模板标识：`data-template="signal-ledger-v1"`
- 响应式双列卡片网格，移动端单列
- sticky 导航栏 + 滚动进度条
- 编者补充卡片：虚线边框 + 橙色徽章
- 编码：UTF-8，行尾：LF，样式脚本全部内联
